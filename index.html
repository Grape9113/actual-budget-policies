Privacy Policy

Last updated: 26 October 2026

Personal use

This is a private, non-commercial application that I use exclusively to manage my personal finances. It connects my private Actual Budget instance to my own bank accounts through Enable Banking. The application is not offered to the public.

Banking information

The application retrieves account balances and transactions from my own bank accounts. I authorize access to this information through my bank as part of the bank authorization process.

Storage and use

Retrieved financial data is stored in my private Actual Budget instance hosted on PikaPods and used for my personal budgeting and financial management. The integration uses Enable Banking to retrieve the data and PikaPods to host my Actual Budget instance. These providers process information as needed to provide their respective services.

I do not sell financial data or use it for advertising.

This policy website

This public website contains only these policy documents. It does not connect to my bank accounts or display financial data. It uses no cookies, analytics, or tracking scripts. GitHub Pages hosts this website and may process technical request information as part of providing its hosting service.
